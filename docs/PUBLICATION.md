# Repository publication boundary

The owner explicitly authorized creating and publishing the separate `ahif-html`
repository after its initial local implementation delivery. Earlier statements
that no commit, push or publication had occurred describe that historical
checkpoint. They are not the current publication instruction.

## Included material

The repository contains the extractor library/CLI, versioned profiles and schemas,
runtime prompts, tests, newly constructed fictional examples, reproducible dependency
lock, documentation and pinned AHIF reference copies. Related projects remain
[AHIF](https://github.com/jaykobdetar/ahif) and
[Account History Analyzer](https://github.com/jaykobdetar/account-history-analyzer).
The extractor does not change their contracts, engine, Reddit bridge or old studies.

A selected [initial-delivery evidence summary](../provenance/initial-delivery/README.md)
retains safe test/replay counts, synthetic evaluation outcomes and reference
identities. It identifies its original evidence; producing the summary is not a
new execution of those tests or model calls. All live successes, failures and
abstentions remain distinguishable from manual-plan or mock tests.

## Material retained only locally

- The full `qa/` history, capture/index sidecars, model requests/responses, local
  execution logs and machine-specific receipt paths.
- Private credentials, SSH keys, host-key databases, deployment controls and
  resource/timer identifiers; local environments, caches and built distributions.
- The historical approved development configurations
  `examples/model-config.live.forum.json` and
  `examples/model-config.live.reviews.json`.
- The detailed historical `docs/RUNPOD-PLAN.md`; its public replacement is the
  aggregate [Runpod summary](RUNPOD-SUMMARY.md).

Those files remain excluded even when their underlying capture text is fictional.
Publishing the code does not automatically authorize publishing model transcripts,
private evidence, source-account mappings or a future capture. The public live
configuration templates have approval disabled and require an explicit data scope
before inference.

References to `qa/` in technical documents name the local historical evidence.
They are not missing runtime inputs or an instruction to retrieve private files.
The shipped examples and model-free quickstart are self-contained; running them
creates a new, separately identified result.

## Licenses and declarations

No explicit project license has been selected for this extractor or the pinned
AHIF reference. No license text or license expression has been invented during
publication preparation. The owner authorized publishing this repository;
public visibility is not represented as a general license grant.

Third-party runtime/test packages retain their own declarations and provenance
in [DEPENDENCIES.md](DEPENDENCIES.md). The AHIF reference copies retain the exact
reviewed bytes and attribution in [REFERENCE-PROVENANCE.md](REFERENCE-PROVENANCE.md).
Capture access, redistribution, authorship and dataset-license declarations remain
separate evidence claims. Unknown remains valid; this repository supplies none of
those permissions for future source data.

The pre-edit versions of publication-adjusted delivery documents remain preserved
under local `qa/publication-preparation/original-docs/`. Documentation updates do
not rewrite earlier execution receipts.
